# Αποθηκάριος

The development of this project (pipelines, issues, etc.) should be followed directly on the [actual repo site](https://git.windmaker.net/a-castellano/apothikarios) rather than on GitHub, which only hosts a mirror.

![The Go gopher in a lab coat stacking building blocks inside a vast warehouse of glass jars, each holding blocks under a clock and a date label, connected by brass pipes](docs/media/apothikarios.jpg)

Αποθηκάριος (apothikarios, Greek for "storekeeper") aims to be a utility for managing [aptly](https://www.aptly.info/) mirrors, local repos, snapshots and publications, with declarative config, update schedules, automatic publications and improved management of aptly resources.
